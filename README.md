# Md. Borhan Uddin — Personal Website

A responsive, SEO-friendly professional profile generated from the CV.

## Publish with GitHub Pages

1. Create a new **public** GitHub repository, e.g. `borhan-uddin`.
2. Upload `index.html`, `style.css`, `script.js`, `robots.txt`, and `sitemap.xml`.
3. In `index.html`, replace:
   - `borhanuddin01-1` with your GitHub username.
4. In `sitemap.xml` and `robots.txt`, the correct live URL is already configured.
5. GitHub → repository → **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select `main` and `/root`, then save.
8. Your site will normally be available at:
   `https://borhanuddin01-1.github.io/borhan-uddin/`
9. Add the final URL to Google Search Console and submit `sitemap.xml`.

## Privacy

The public version intentionally excludes the CV's full home address, date of birth, religion and phone number. It includes the professional email address supplied in the CV and public social-profile links.
